# Court-Vision-2026

The following code has last been updated on 06/14/2026.

CourtVision's goal is to provide Basketball analysis and tracking of players in not only the NBA league environment, but also in FIBA and South Korean basketball leagues games too! Using our custom detection model and optical flow tracking to maintain accurate readings of player jersey numbers, our program can generate a graph that can be used after each quarter-length game to visually show jumpshots and where they were either missed or made. 

In the future, we aim to also add functionality for team association and better accuracy readings of players.
